| | |
|---|---|
| Handle | [@\_cosmicearth](https://x.com/_cosmicearth) |
| Post | <https://x.com/_cosmicearth/status/2106376336990425596> |

| Posted | 2026-10-03, +21 h at capture |
| Format | 1080×1080, 6.0 s, 60 fps, H.264, no audio, 5.6 MiB |
| Text | "Not only is the Universe stranger than we think, it is stranger than we can think." — Werner Heisenberg |

**What was inspected:** all 6 grid frames plus a 15-frame contact sheet at 2.5 fps.

**What it gives us:** the volumetric medium. Dense point sources of many colours, elongated
comma-shaped smudges (edge-on galaxies), grey-brown dust filaments, voids, soft halos on bright
stars, one red nebular knot. Full-bleed, zero UI. Depth is communicated purely by parallax drift.

## Ref B — "Encyclopedia Cosmologica"

| | |
|---|---|
| Handle | [@RuiHuang_art](https://x.com/RuiHuang_art) |
| Post | <https://x.com/RuiHuang_art/status/2106220703716655174> |
| Media | <https://video.twimg.com/amplify_video/2106216653390512128/vid/avc1/2874x1440/uYqg9w3ujhQAwxpu.mp4> |
| Title | 宇宙百科全书 / *Encyclopedia Cosmologica* (subtitle: 文明指南) |
| Posted | 2026-10-03 03:12 UTC |
| Format | 2874×1440, 53.1 s, 24 fps, H.264 + AAC, 63.3 MiB |
| Author's note | Interactive artwork with 5000+ sci-fi pieces; to launch to Alpha Centauri with Fermi Explorer in 2029; inspired by Jon Lomberg and Carl Sagan |

**What was inspected:** 16-frame contact sheet across the full 53 s, plus full-resolution crops of
the title lockup, the bottom-left fact card, the bottom-centre readout, and a node cluster.

**What it gives us:** the information language. Near-black canvas, faint nebulosity, glowing nodes
with anamorphic starbursts, thin multi-hue light ribbons between them, wireframe reticles around
each node, scattered `+` spark markers, micro-typography, and a minimal HUD (title lockup, thin top
nav, fact card, boxed readout, red provenance badge).
